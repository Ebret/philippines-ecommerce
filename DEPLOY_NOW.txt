# GinTea Theme Deployment - Copy & Paste Commands

========================================
STEP 1: CONNECT TO VPS
========================================

Open PuTTY or your SSH client and connect to:
Host: 109.205.181.119
Port: 22
Username: root

Or use this command:
ssh root@109.205.181.119


========================================
STEP 2: NAVIGATE TO APPLICATION
========================================

cd /var/www/html/ecom/app
pwd


========================================
STEP 3: CREATE BACKUP
========================================

git branch backup-gintea-theme-$(date +%Y%m%d-%H%M%S)
git branch | grep backup


========================================
STEP 4: FETCH AND CHECKOUT
========================================

git fetch origin
git checkout feature/relivator-ui-integration
git pull origin feature/relivator-ui-integration


========================================
STEP 5: VERIFY COMMIT
========================================

git log -3 --oneline

Expected to see:
- 0ea6f21 docs: add comprehensive theme comparison guide
- f07d0bf feat: implement GinTea-inspired herbal tea shop theme
- cc1e791 docs: add quick deployment guide and commands


========================================
STEP 6: BUILD APPLICATION
========================================

npm run build

Wait for: "✓ Compiled successfully"
This takes 1-2 minutes


========================================
STEP 7: RESTART PM2
========================================

pm2 kill
sleep 3
pm2 start ecosystem.config.js
pm2 save


========================================
STEP 8: VERIFY DEPLOYMENT
========================================

pm2 status

Both processes should show "online"


========================================
STEP 9: TEST SITE
========================================

curl -I http://localhost:3000
curl -I https://extremelifeherbal.com

Both should return HTTP 200 or 304


========================================
STEP 10: CHECK LOGS
========================================

pm2 logs --lines 20

Press Ctrl+C to exit


========================================
DEPLOYMENT COMPLETE!
========================================

Now open in your browser:
https://extremelifeherbal.com

You should see:
✓ Matcha green header (brighter than before)
✓ Soft cream background (lighter, more elegant)

Test dark mode:

========================================
TROUBLESHOOTING
========================================

Build fails:
rm -rf .next
npm run build

PM2 won't start:
pm2 kill
sleep 5
pm2 start ecosystem.config.js

Old theme still showing:
Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

Site not accessible:
systemctl status nginx
systemctl restart nginx
